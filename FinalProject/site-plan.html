Overview

Purpose

To help GM's for TTRPGs create and manage a dynamic army of followers for villains and to surport a unique type of campaign.

Audience

GM's for TTRPGs like Dnd or pathfinder.

Dynamic elements

This program will help users generate generals, commanders, or villains of intrest within an orginzation. Not only will this program help with names, but also with weaknesses, stregths, fears, relationships, goals, ect.

Pseudocode for your project

Start the application Store organizations and army members in arrays of objects Display the default organization and its members When the user selects an organization: Update the organization name and description Display only members belonging to that organization Update the organization statistics When the user clicks Generate Member: Randomly choose a role Randomly choose a name Randomly choose strengths, weaknesses, fears, and goals Create a new member object Add the member to the roster Display the new member When the user searches for a member: Compare the search text with member names and roles Display matching members When the user selects a filter: If the filter is "Active": Display only active members If the filter is "Defeated": Display only defeated members Otherwise: Display all matching members When the user clicks a member card: Display that member's complete details When the user changes a member's status: Update the member object Recalculate the organization statistics Refresh the roster display
